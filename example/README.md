# Supreme Animations Showcase App ⚡

This example application demonstrates the core features, choreography tools, and flagship plugins of the `supreme_animations` package.

## 📱 Showcase Tabs

1. **Tweens & Controls**: Interactive progress scrub bar, speed scaling (0.2x - 3.0x), yoyo playback, and playback state controls (play, pause, restart, reverse).
2. **Timeline**: Multi-target choreography demonstrating timeline sequence positions, relative offsets, and label cues.
3. **Stagger**: 1D and 2D grid matrix stagger cascades with configurable origins (center, edges, start, random).
4. **ScrollTrigger**: Scroll-driven viewport animations with smooth scrub damping and pinned trigger boundaries.
5. **FLIP**: Seamless layout reordering and view morphing between grid and list layouts.
6. **Text Effects**: Typewriter effect, character scramble decryption, and staggered word/character reveals.
7. **MotionPath**: Curved Bezier spline traversal with live tangent alignment and automatic rotation (`autoRotate`).
8. **Draggable & Inertia**: Physics-driven gesture dragging and flinging with momentum deceleration.

## 🚀 Running the Example

Run on your connected desktop, mobile device, or browser:

flutter run
